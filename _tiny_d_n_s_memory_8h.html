Detailed Description

Allocation helpers shared by the TinyDNS containers (LRU cache and RAM blocklist). They place memory in PSRAM when the board has it.

  • ESP32 with BOARD_HAS_PSRAM: heap_caps_calloc(MALLOC_CAP_SPIRAM), falling back to internal RAM if PSRAM is unavailable.
  • RP2350 with RP2350_PSRAM_CS (arduino-pico): pmalloc(), falling back to internal RAM.
  • Otherwise: calloc() from internal RAM.

Define TINY_DNS_NO_PSRAM to always use internal RAM. Allocation must happen after PSRAM is initialized (in setup(), not in a global constructor). Memory from tinyDnsAlloc() must be released with tinyDnsFree(); it is zeroed.
