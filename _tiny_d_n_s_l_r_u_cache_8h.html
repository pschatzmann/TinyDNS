Detailed Description

LRU cache for DNS records with a runtime capacity, optionally placed in PSRAM.

Entries are keyed by (name, qtype). Names are compared case-insensitively and stored lower-cased. When the cache is full, the least recently used entry is evicted. Entries carry an absolute expiry time in millis(), and expired entries are dropped on lookup.

The entry table is allocated by begin(), not by the constructor, so that PSRAM setup can run first. Memory placement:

  • ESP32 with BOARD_HAS_PSRAM: heap_caps_calloc(MALLOC_CAP_SPIRAM), falling back to internal RAM.
  • RP2350 with RP2350_PSRAM_CS (arduino-pico): pmalloc(), falling back to internal RAM.
  • Otherwise: calloc() from internal RAM. Define TINY_DNS_NO_PSRAM to always use internal RAM.

Usage:

TinyDNSLRUCache cache;
cache.begin(32); // in setup()
uint8_t addr[4] = {93, 184, 216, 34};
cache.put("Example.com", 1, addr, 4, millis() + 300000UL);
const TinyDNSLRUCache::Entry *e = cache.get("example.com", 1, millis());
