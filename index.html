TinyDNS

[](LICENSE)

TinyDNS is a header-only DNS library for Arduino. It sends DNS queries over any Arduino Client, so it works with plain DNS over TCP (port 53) and DNS over TLS (port 853).

It provides:

  • **TinyDNSClient**: resolves A and AAAA records.
  • **TinyDNSServer**: a caching DNS server with a static host table and an LRU cache. Cache misses are forwarded to an upstream TinyDNSClient.

Installation

Arduino IDE

Download the library as a ZIP file and add it with Sketch → Include Library → Add .ZIP Library…, or clone it into your Arduino libraries folder:

cd ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/TinyDNS.git

PlatformIO

lib_deps = https://github.com/pschatzmann/TinyDNS.git
