Detailed Description

Least-recently-used cache with a runtime capacity.

Capacity is limited to kMaxCapacity (254) because LRU links are stored as 8-bit slot indices. Memory use is capacity * sizeof(Entry) (about 90 bytes per entry). Each put() copies the name and RDATA into the table, so callers keep ownership of their buffers. The cache is not thread-safe; use it from one task or loop at a time.
