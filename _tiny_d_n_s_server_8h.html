Detailed Description

Caching DNS-over-TCP server for Arduino, backed by an LRU cache.

Accepts DNS queries on a stream Client (e.g. a WiFiClient obtained from a WiFiServer listening on port 53), answers A/AAAA questions from an LRU cache and forwards cache misses to an upstream TinyDNSClient.
