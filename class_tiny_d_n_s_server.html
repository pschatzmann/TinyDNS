Detailed Description

Caching DNS server that answers queries from an LRU cache and forwards misses to an upstream TinyDNSClient.

Usage: accept a connection on a server socket and pass the client to handle(). Each call reads exactly one query and writes one response. The upstream client must use a different Client than the incoming connection, and must outlive this server.

An optional static host table (see the constructors) is checked first; its entries are answered without touching the cache or the upstream server. The host table array must outlive this server.
