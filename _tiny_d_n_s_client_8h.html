Detailed Description

Header-only DNS-over-TCP/TLS resolver for Arduino.

Resolves hostnames by speaking DNS over a stream Client (RFC 1035 section 4.2.2 TCP framing: each DNS message is prefixed by a 2-byte big-endian length). Because it only relies on the generic Arduino Client interface, it works with any Client implementation: WiFiClient/EthernetClient (plain DNS-over-TCP, port 53) or WiFiClientSecure (DNS-over-TLS, port 853) against a resolver that supports it (e.g. 1.1.1.1:853, 8.8.8.8:853).

WiFiClient net;
TinyDNSClient dns(net, IPAddress(1, 1, 1, 1));
IPAddress ip;
if (dns.resolve("example.com", ip)) { ... }
